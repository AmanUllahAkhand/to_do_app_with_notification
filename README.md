# To-Do List ⏰ – The Ultimate Reminder App

A **beautiful, powerful, and reliable** to-do list app built with **Flutter** that **never lets you miss a task** — even when your phone is on silent or the app is closed.

Featuring **real alarm clock behavior** — loud repeating alarms, full-screen popups, and critical alerts that bypass Do Not Disturb.


---

### Features

| Feature                        | Description |
|--------------------------------|-----------|
| **Real Alarm Clock Behavior**  | Loud repeating alarm + full-screen popup (even when app is killed) |
| **Critical Alerts (iOS)**      | Bypasses Silent mode & Do Not Disturb |
| **Insistent Alarm (Android)**  | Repeats sound until dismissed |
| **Smart Reminders**            | Uses real database ID — no duplicates, perfect editing |
| **Priority Levels**            | High, Medium, Low with color coding |
| **Categories**                 | Home, Work, Shopping, Personal |
| **Clean & Modern UI**          | Built with GetX, beautiful animations |
| **100% Offline**               | Works without internet |
| **Survives Reboot**            | Reminders reschedule after phone restart |

---

### Tech Stack

- **Framework**: Flutter (Cross-platform)
- **State Management**: GetX
- **Local Database**: SQflite
- **Notifications**: `flutter_local_notifications` + Critical Alerts
- **Architecture**: Clean Architecture + Repository Pattern
- **Supported Platforms**: Android 8+ & iOS 13+
